# 幸福階梯

解壓後用瀏覽器打開 `index.html`。要改文章或標題，請用文字編輯器打開同一個檔案。

- `index.html`：封面、前言、幸福階梯、三章、總結及註釋，已按段落加上 HTML 註解。
- `site.css`：響應式版面和網頁樣式。`layout.css` 保留 Figma 圖層的排版。
- `site.js`：閱讀進度、階梯作答、即時排名和查看數據。
- `assets/`：Figma 插圖和圖表的圖形素材。
- `data/`：官方 Excel、整理過的 CSV、Assignment 2 網頁資料和資料來源對照。

請把這些檔案留在同一資料夾，這樣圖形和資料連結才能正常載入。
